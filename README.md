# 🌱 청년마음이음상담소

20·30 청년을 위한 **성장 중심 상담소** 웹사이트입니다.
정신질환 치료가 아니라 번아웃, 취업·진로, 퍼스널 브랜딩, 자기 이해처럼
"아프지는 않지만 방향이 흐릿한" 시기를 함께 정리하는 곳으로 기획했습니다.

## 컨셉

- **톤앤매너** — 따뜻하고 밝은 크림/살구/버터 색조, 둥근 모서리, 부드러운 그림자
- **메시지** — "아프지 않아도 괜찮아요. 잘 살고 싶어서 오는 곳이니까요."
- **타깃** — 취업 준비생, 사회초년생, 이직·퇴사를 고민하는 3년 차 직장인

## 페이지 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 히어로, 고민 체크리스트, 프로그램 4종, 진행 방식 4단계, 후기, FAQ, CTA |
| `programs.html` | 프로그램 상세 커리큘럼, 단회 세션, 이용료 안내 |
| `about.html` | 상담소 이야기, 4가지 약속, 상담사 소개, 오시는 길 |
| `apply.html` | 무료 첫 상담 신청 폼 (클라이언트 검증 포함) |

## 기술 구성

의존성 없는 **정적 사이트**입니다. 빌드 과정이 필요 없습니다.

```
index.html / programs.html / about.html / apply.html
assets/
  css/style.css   — 디자인 토큰 + 컴포넌트 스타일 (공용)
  js/main.js      — 모바일 메뉴, FAQ 아코디언, 스크롤 등장, 카운트업, 폼 검증
```

- 폰트: [Pretendard](https://github.com/orioncactus/pretendard) (CDN, 시스템 폰트 폴백)
- 반응형: 960px / 720px 브레이크포인트
- 접근성: 스킵 링크, `aria-expanded` 토글, 포커스 링, `prefers-reduced-motion` 대응

## 실행

```bash
python3 -m http.server 8000
# http://localhost:8000
```

파일을 직접 열어도(`file://`) 동작합니다.

## 커스터마이징

색상·간격은 `assets/css/style.css` 상단 `:root` 토큰만 바꾸면 전체에 반영됩니다.

```css
--apricot: #ff8a5b;   /* 메인 포인트 */
--sage:    #6fa287;   /* 보조 (안정감) */
--butter:  #ffcf6b;   /* 강조 (밝음) */
--lilac:   #a89ad6;   /* 보조 (부드러움) */
```
